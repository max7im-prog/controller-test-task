# Test task with multi-threading

This repository contains a program that implements requirements described in **TASK.md**

## Building the program

The program is built using the default build process with Cmake and C++

```sh
git clone https://github.com/max7im-prog/controller-test-task.git
cd ./controller-test-task
mkdir ./build
cd ./build
cmake ..
cmake --build .
```

## Executable

Executable is located in **build/bin**

## Test executable

Test executable is also located in **build/bin**
